# 🗣️ Quiz-Speak Assistance System

## Overview
Quiz-Speak is an accessible text-to-speech MCQ system that transforms technical questions into audio, providing an inclusive interface for visually impaired users. It automates audio generation and allows for seamless navigation of assessments.

## 💡 Features
- Converts MCQs to audio using Google Text-to-Speech (gTTS).
- Supports a dynamic question database.
- Clean web interface using HTML/CSS/JavaScript.
- Backend integration with MySQL for storing and retrieving questions.

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: MySQL, Python
- TTS Engine: gTTS (Google Text-to-Speech)

## 🎯 Impact
- Designed for inclusive education.
- Increases accessibility for visually impaired learners.
- Led a cross-functional team of 5 developers.

## 📁 How to Run
1. Clone the repo.
2. Setup MySQL DB and import the question dataset.
3. Run Python Flask server.
4. Open `index.html` in browser.
